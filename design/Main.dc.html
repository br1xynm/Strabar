El sistema de una app
que se usa de noche

Fundamentos del rediseño: color, tipografía, espacio y movimiento. La marca (rojo señal y calidez) se mantiene; el lienzo pasa del papel crema a la noche.

01

Principios

NOCHE PRIMERO

La web se parece a la app a la 1 a.m.

El fondo oscuro no es una moda: es el contexto real de uso. El crema queda como respiro, no como base.

EL DATO ES EL HÉROE

Kilómetros, paradas y tiempo, en mono

Cifras tabulares con etiqueta corta. Nada de estadística decorativa: si un número no cambia una decisión, fuera.

UNA SOLA ACCIÓN

«Probar la demo», repetida

El rojo señal solo se usa para eso. Todo lo demás es contorno o texto: el CTA nunca compite consigo mismo.
